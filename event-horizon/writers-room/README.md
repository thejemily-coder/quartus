# ⚠ WRITERS' ROOM: SEALED

**Player: do not read anything in this folder.** It holds every secret, twist, long arc, and answer in *The Event Horizon*. The show is written to be played blind, and your choices shape these arcs without you knowing their shape. The player-facing material is in `../player/`.

---

## For writing agents

This folder is the single source of truth for the show. Read it before writing or reviewing any episode.

| File | What it is |
|---|---|
| `SERIES_BIBLE.md` | World, mythology, the full secret arc for 20+ seasons, every character's public face and private truth, tone and content rules. |
| `CHARACTERS.md` | Voice sheets: how each character talks, what they want, what they hide, and how they change. Use it for voice QA. |
| `MECHANICS.md` | The full rules: dice systems, stats, powers, life sim, bonds, heat, and the ledger schema. The engine implements exactly this. |
| `SEASON_01.md` | The Season 1 plan, episode by episode. It is a plan, not a script: player choices bend it. |
| `PROCESS.md` | The production pipeline for each new episode: read the save, update canon, write, QA, build, publish. |
| `canon/ledger.json` | The machine canon: who knows what, open threads, character states, the timeline. Update it after every episode from the player's real save. |
| `canon/episodes/` | One canon file per played episode. Each records what actually happened in this playthrough, taken from the save. |

**Golden rule:** this playthrough's canon is whatever the player's save says happened. The bible gives intentions; the save gives facts. When they conflict, the save wins, and the bible gets updated.
