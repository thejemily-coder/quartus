# Projects in this repo
- `hard-saying/` — **The Hard Saying**, the player's current interactive drama (Fall 2009, Jack Costigan & Lena Broussard).
  To make the next episode, follow `hard-saying/README.md` exactly: read the save from the artifact db, run a notes
  session with AskUserQuestion, run `hard-saying/writers/next-episode.workflow.js`, build, smoke-test, republish to the
  same artifact URL, commit and push. Never reveal hidden canon (bible, outlines, ledgers) to the player.
- `dynasty/` — an earlier game project (Surface Rights); not active.
