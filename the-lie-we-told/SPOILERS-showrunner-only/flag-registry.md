# FLAG REGISTRY (SHOWRUNNER ONLY)

Every flag the series has set, what it means, and how later episodes must use it. Flags persist for the whole series. Unset = false/0. Add a section per episode. **Rule:** a flag that a later episode ignores must be ignored on purpose and noted here (why). Echo discipline: every end-card echo pays off within 1–3 seasons.

Legend for "Use": **E2** = must surface in Episode 2 · **S1** = surface this season · **LONG** = dormant lever, multi-season · **COLOR** = flavor only (callback lines, texture; never gates a plot beat).
